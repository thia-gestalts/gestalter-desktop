# Gestalter desktop

A local-first workspace for writing, connecting and revisiting notes, organizing a Luhmann-style Zettelkasten and working with academic sources. Use ordinary React routes and reusable components such as the note editor. A Python backend owns local persistence and desktop integrations. Ship a usable Linux application first and keep packaging, file selection and platform paths replaceable for macOS and Windows.

Keep general artifacts simple. “Book X” exists once as a named artifact. A desktop-owned academic record references that artifact and holds citation keys, BibTeX types and fields. Several bibliographic records can refer to the same artifact. A scholar can keep, compare or reconcile them without affecting someone else’s ability to refer to the book.

Desktop participates in optional automatic Olymp sync of the entire base. It can show what was practised elsewhere using learner events and their targets alone.
