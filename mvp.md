# First usable desktop release

- **Notes.** Create, search, read, edit and delete notes, with Markdown, relationships and attachments. Reuse the editor when working from another route.
- **Zettelkasten.** Choose a root, place a note after another or branch from it, revisit unplaced notes, opt individual notes out, and surface inconsistent placements.
- **Academic sources.** Paste/import BibTeX, edit bibliographic fields, compare candidate duplicates, update an entry deliberately, export a .bib file, and attach notes or annotations to sources. Distinct entries with the same work title may share a single artifact.
- **Plaintext inbox.** Import a folder of texts, revisit an item, create one or several notes from it, then defer or remove the inbox item. Removing an item affects the imported copy. Leave the source folder intact.
- **Recent practice.** Show a read-only list of recently practised facts and skills, most recent first, with target labels and time. A score-neutral topic engagement alone does not place a skill on that list.
- **Account.** Work locally and optionally sign in to Olymp for automatic whole-base sync, including attachments and app-specific records.

Acceptance on a clean Linux installation: import a folder, make and place a note, add a citation to a named artifact, sign in, then see an independently generated practice attempt with its skill label.
